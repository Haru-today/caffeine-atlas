Caffeine Atlas는 회원가입이나 로그인 없이 이용할 수 있는 연구·교육용 유전자형 분석 서비스입니다.

확인 필요: 운영 책임자와 공식 개인정보 문의 연락처, 연구 저장 데이터의 보관 기간·삭제 절차, 위탁 및 국외 이전 사항은 아직 검증·확정되지 않았습니다. 이 안내를 법적 개인정보처리방침의 완결 또는 개인정보보호 인증 표시로 해석하지 마세요.

1. 공개 분석과 입력 정보

4개 SNP(rs762551, rs2069514, rs2472297, rs6968865)의 유전자형과 Sample ID, 검사 날짜·검체 종류·성별 선택값 등이 연구용 모델 분석에 사용될 수 있습니다. 현재 공개 체험 모드에서는 입력값을 브라우저에서 계산하고 상세 리포트를 로컬 파일이나 브라우저의 PDF 인쇄 기능으로 저장할 수 있습니다. 공개 체험의 분석값은 자동으로 Google Sheets에 전송되지 않습니다.

실명, 학번, 환자번호, 식별 가능한 실제 연구 대상자 검체 정보는 입력하지 마세요. 연구 데이터 입력·활용에는 별도 적법한 동의·관리 절차가 필요합니다.

2. 서버 저장 기능과 한계

연구용 화면/코드에는 선택적 Google Apps Script·Google Sheets 저장 기능과 엑셀 일괄 처리를 위한 코드가 남아 있을 수 있습니다. 현재 공개 체험에서 그 서버 저장 기능은 비활성화돼 있습니다. 하지만 과거 Apps Script 배포 URL의 서버 측 접근 가능 여부와 이미 저장된 연구 데이터의 실제 관리·삭제 상태는 별도 확인이 필요합니다. ‘화면에서 저장 버튼이 보이지 않는다’는 사실만으로 과거 서버 배포가 완전히 차단됐다고 단정하지 않습니다.

3. 외부 제공사와 보유·삭제

웹사이트는 GitHub Pages를 통해 공개되며 방문 접속 로그 등은 호스팅 제공사의 정책을 따릅니다. 공개 사이트에서 다운로드한 PDF·HTML·CSV, 스크린샷, 사용자가 발송한 이메일은 이용자 기기 또는 이메일 서비스에 남으며 페이지를 닫거나 브라우저 입력을 삭제해도 자동 삭제되지 않습니다.

Google Apps Script/Sheets에 과거 저장된 자료가 있다면, 그 보관 기간과 삭제 권한은 별도의 운영자 점검이 필요합니다. 브라우저 로컬에서 작성한 결과와 과거 연구 저장 자료를 동일한 것으로 취급하지 않습니다.

4. 문의와 정보주체 권리

공개 문의 양식은 사용자의 이메일 앱을 열어 메시지 내용을 작성하는 방식일 수 있습니다. 이메일에는 작성자가 입력한 이름·연락처·문의 내용 등이 포함될 수 있습니다. 민감한 실제 검체·환자 정보를 공개 GitHub 이슈나 이메일 내용에 작성하지 마세요.

개인정보 열람·정정·삭제 등 공식 요청의 운영 주체, 신원 확인 방식 및 전용 비공개 연락 수단은 정식 운영 전에 마련해야 합니다. 일반 기능 오류는 프로젝트 GitHub 이슈로 접수할 수 있으나, 이곳은 비공개 개인정보 민원 창구가 아닙니다.
